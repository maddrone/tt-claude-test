# 宝石消消乐 — Match-Three Puzzle Game

类似开心消消乐的 Python 益智游戏，25 个关卡，难度逐步提升。

## 运行要求

- Python 3.8+
- macOS / Linux / Windows
- pygame 2.x

## 快速开始

```bash
# 安装依赖
pip install pygame

# 运行游戏
python main.py
```

或者直接运行安装脚本：
```bash
bash setup.sh
```

## 键盘操作

| 按键 | 功能 |
|------|------|
| ↑ ↓ ← → | 移动光标 |
| 空格 / Enter | 选择宝石 / 确认交换 |
| H | 显示提示 |
| P | 暂停 / 继续 |
| M | 开关背景音乐 |
| ESC | 返回标题 / 取消选择 |
| 1–9, 0 | 在标题界面直接选择关卡 (1–10) |

## 游戏说明

- 交换相邻宝石，使3个或更多同色宝石相连消除
- 消除4个 → 生成**条纹宝石**（清除整行或整列）
- 消除5个 → 生成**彩虹宝石**（清除棋盘上所有同色宝石）
- 消除6个+ → 生成**炸弹宝石**（3×3范围爆炸）
- 连击可获得分数加成

## 关卡特色

| 关卡 | 特色 |
|------|------|
| 1–5  | 基础消除，入门练习 |
| 6–10 | 冰块障碍登场 |
| 11–14 | 石头障碍，棋盘受限 |
| 15–19 | 限时挑战，节奏加快 |
| 20–25 | 全冰封 + 极限步数，大师级考验 |

## 背景音乐

游戏首次运行时会自动下载来自 [soundimage.org](https://soundimage.org) 的免费音乐
（Eric Matyas，CC BY 4.0 授权）。网络不可用时游戏也可正常运行（仅无背景音乐）。

## 文件结构

```

├── main.py        # 入口
├── game.py        # 游戏状态机
├── board.py       # 棋盘逻辑
├── levels.py      # 25 个关卡配置
├── renderer.py    # 渲染（程序生成宝石图形）
├── audio.py       # 音效（程序生成）+ 背景音乐
├── requirements.txt
└── assets/
    └── sounds/    # 自动下载的背景音乐
```
